ჩემ შესახებ ინფორმაცია

მე ვარ სანდრო, ვარ 14 წლის და ძალიან მაინტერესებს პროგრამირება.

მე ვსწავლობ HTML, CSS და JavaScript. მომწონს ახალი ტექნოლოგიების სწავლა და სხვადასხვა პროექტებზე მუშაობა.

ახლახანს შემოვედი GOA-ში და ძალიან მომწონს

პროგრამირების ენების შესახებ

Python

Python შექმნა გვიდო ვან როსუმმა. მის შექმნაზე მუშაობა 1989 წელს დაიწყო, ხოლო პირველი ვერსია 1991 წელს გამოვიდა. Python არის მაღალი დონის, ზოგადი დანიშნულების პროგრამირების ენა.

CSS

CSS-ის შექმნა 1994 წელს ჰაკონ ვიუმ ლიმ დაიწყო. CSS-ის პირველი ვერსია 1996 წელს გამოქვეყნდა. ის პროგრამირების ენა არ არის — CSS არის სტილების აღწერის ენა, რომლითაც ვებგვერდის გარეგნობას ვქმნით.

JavaScript

JavaScript შექმნა ბრენდან აიქმა 1995 წელს. ის არის მაღალი დონის პროგრამირების და სკრიპტების ენა, რომელიც ხშირად ვებგვერდებს ინტერაქტიულობას მატებს.
