Explanation of the following tags in html.

Form: a container that holds input fields and sends their data when submitted. like the user's birth date, password, username, email and more


Input: a field where the user types or chooses something.


Label: to tell the user what to type in the following field. like password, username, birth date.


Explanation of the following attributes in html.


Type: to tell the user what kind of field it is. and the differences. when the user types his password in a password type, it will display only asteriks, for privacy reasons.


Id: a unique name for an element, so it can be identified by the computer.


For: connects a label to an input. Its value must match the input's ID
